# DAPO (Decoupled Clip and Dynamic sAmpling Policy Optimization) -- 解耦裁剪与动态采样策略优化

> [DAPO原论文](https://export.arxiv.org/pdf/2503.14476#3#1)

## 一、DAPO的诞生：当GRPO的“复现困境”遇上长链推理的“熵崩塌”

在前三篇文章中，我们分别讲解了PPO的价值网络困境、DPO的数学降维以及GRPO的组内相对优势革命。然而，即便GRPO已经极大地提升了资源效率，研究者们在将其应用于**长思维链（Long Chain-of-Thought）推理模型**的训练时，依然遭遇了一系列棘手的工程问题。

2024年底至2025年初，随着OpenAI o1和DeepSeek R1的发布，**测试时缩放（Test-time Scaling）——让模型在推理时生成更长的思维链来获得更优答案**——成为大模型领域最前沿的方向。而驱动这一变革的核心技术，正是大规模强化学习。

然而，问题在于：**关键的技术细节被隐藏了**。无论是OpenAI的博客还是DeepSeek R1的技术报告，都没有公开其RL训练的具体算法和关键配方。社区研究者发现，即便严格按照DeepSeek公开发表的方法操作，**依然难以复现其效果**。

字节跳动Seed团队与清华大学AIR研究院联合实验室SIA-Lab在复现GRPO时，遇到了一个令人警醒的现实：**基于Qwen2.5-32B模型运行naive GRPO，在AIME 2024上仅获得了30分**——而DeepSeek的RL报告显示为47分。经过深入分析，他们发现naive GRPO在**长CoT场景**下面临着**熵崩塌、奖励噪声、训练不稳定**等多个关键问题。

更令人担忧的是，整个社区都遇到了类似的复现困难。这表明DeepSeek R1论文中可能**省略了构建工业级、可扩展、可复现RL系统所必需的关键训练细节**。

正是在这样的背景下，**DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization，解耦裁剪与动态采样策略优化）** 应运而生。DAPO并非一个全新的算法框架，而是**在GRPO的基础上，针对长CoT RL场景引入四项关键训练优化技术**，将GRPO从“实验室玩具”升级为“工业级武器”。

---

## 二、GRPO在长CoT场景下的四大困境

要理解DAPO的创新，首先需要理解GRPO在长CoT RL训练中遇到的具体问题。

### 2.1 熵崩塌（Entropy Collapse）

在naive GRPO训练中，研究团队观察到一个致命现象：**策略的熵在训练初期就迅速下降**。这意味着**模型的输出分布变得越来越“确定”**——某个组内的采样回答**趋近于完全相同**。

熵崩塌为什么可怕？**熵是衡量模型探索能力的指标**。熵过低意味着**探索能力严重不足**，模型只会生成少数几种“**安全**”的回答模式，无法探索到可能带来**更高奖励**的新推理路径。这直接导致了RL scaling的停滞。

熵崩塌的根本原因在于**GRPO对称裁剪区间对概率提升幅度的限制过于保守**。在对称的$[1-\epsilon, 1+\epsilon]$裁剪下，无论token原本的概率是高是低，其相对提升比例都被限制在同一个上界$1+\epsilon$之内。这意味着**低概率的“探索性”token即便获得了正向优势，也无法得到足够的概率增幅**——它们始终难以“翻身”。与此同时，高概率token在Softmax归一化的“挤出效应”下进一步挤压低概率token的概率质量，导致模型的输出分布迅速收窄，熵值急剧下降。DAPO的**Clip-Higher策略正是通过放宽上界（从0.2到0.28）** ，给低概率token提供了更大的相对提升空间，从而**从根本上打破了熵崩塌的恶性循环**。

然而，由于Softmax归一化的“挤出效应”，高概率token一旦获得正优势，即便自身难以上涨，也会通过分母压缩其他低概率token的概率质量；加之**低概率token在采样中极少获得正向奖励，梯度更新微弱，熵自然迅速崩塌**。

### 2.2 奖励噪声与样本效率低下

在长CoT场景中，模型生成的推理链长度可能达到**数万token**。对于数学推理这类任务，**奖励信号只在最终答案处给出（0或1）** ——这是一个典型的**稀疏奖励**问题。**绝大多数token的生成得不到任何有意义的反馈**。

更糟糕的是，当组内所有回答的奖励**完全相同**（比如全部正确或全部错误）时，GRPO的组**归一化优势全部为0**，这一整组数据**无法提供任何有效的梯度更新信号**，造成巨大的计算浪费。

### 2.3 训练不稳定性

GRPO虽然去掉了价值网络，但在**长序列、大规模并行训练**的场景下，仍然存在**训练不稳定**的问题。**组大小的选择、KL惩罚系数的设置**等超参数，对训练结果的影响呈现出**非单调**的特性，使得调优变得极为困难。

### 2.4 KL散度约束的必要性存疑

GRPO继承了PPO的**KL散度惩罚项**，用于约束策略不要偏离参考模型太远。但在长CoT推理训练中，**模型分布本身就会与初始模型产生显著偏离**——这正是我们想要的，因为长CoT推理本身就是一种全新的行为模式。强行施加KL约束反而可能**限制了模型探索新推理路径的能力**。

## 三、DAPO的四大核心技术创新

DAPO针对上述四个问题，分别引入了四项关键技术。

### 3.1 Clip-Higher：打破熵崩塌的“非对称裁剪”

**解决的问题**：GRPO中对称的裁剪区间$[1-\epsilon, 1+\epsilon]$对低概率token的“上界”压制过强，导致探索不足、熵崩塌。

**解决方案**：DAPO将裁剪区间**解耦**为独立的下界和上界：

$$\text{clip}(r_{i,t}(\theta), 1-\epsilon_{\text{low}}, 1+\epsilon_{\text{high}})$$

其中$\epsilon_{\text{low}}$和$\epsilon_{\text{high}}$可以独立设置。在DAPO的典型配置中，$\epsilon_{\text{low}}=0.2$，$\epsilon_{\text{high}}=0.28$——**上界显著大于下界**。

**原理深度解析**：

这个看似简单的改动，背后有深刻的考量。回顾PPO/GRPO的裁剪逻辑：
- 当优势$\hat{A}_{i,t} > 0$时，算法试图增加该token的概率，此时起作用的是**上界**$1+\epsilon_{\text{high}}$
- 当优势$\hat{A}_{i,t} < 0$时，算法试图降低该token的概率，此时起作用的是**下界**$1-\epsilon_{\text{low}}$

提高上界意味着：**当一个token被判定为“好”时，模型可以更大幅度地提升它的概率**——无论这个token原本的概率是高是低。这就给了那些**原本概率很低但可能带来高奖励的“探索性”token**一个“翻身”的机会。

实验数据证实了Clip-Higher的效果：应用**Clip-Higher**后，**模型的熵不再崩塌，而是呈现出缓慢上升的趋势**，这与最终性能的提升直接相关。在AIME测试集上，Clip-Higher策略将准确率从约30分提升到了接近40分。

### 3.2 Dynamic Sampling：剔除“无效组”的动态过滤

**解决的问题**：当组内所有回答的奖励**全部相同**（全对或全错）时，**组归一化后的优势全部为0**，这组数据无法提供有效的梯度信号，造成计算浪费。

**解决方案**：DAPO引入**动态采样（Dynamic Sampling）** 机制：

1. 对每个prompt采样一组回答
2. **过滤掉那些奖励全部相同（标准差为0）的组**——即全对或全错的组
3. **持续采样**，直到累积足够数量的“有效组”（即组内同时包含正确和错误回答）
4. 用这些**有效组**构成一个训练batch

**原理深度解析**：

动态采样的核心逻辑是：**只有当组内存在奖励差异时，GRPO的组归一化优势才能提供有意义的“相对好坏”信号**。

试想：如果一组5个回答全部正确，它们的奖励都是1，归一化后优势全是0——我们无法从中学到任何东西，因为模型已经做得很好了，但我们不知道“为什么好”。如果一组全部错误，同理。

动态采样通过**强制要求每个batch中的每个组都包含至少一个正确和一个错误的回答**，确保了每个组都能提供**有效的对比信号**；训练batch中的每一个**数据点都有意义**；**样本效率**得到显著提升。

在verl框架的实现中，动态采样通过`filter_groups.enable=True`启用，并且可以设置`max_num_gen_batches`来限制最大尝试次数，防止死循环。

实验表明，**移除动态采样后，DAPO的性能从52%下降到50%**——这2个百分点的差距，正是动态采样的贡献。

### 3.3 Token-Level Policy Gradient Loss：从“句子平均”到“Token精细”

**解决的问题**：GRPO在计算损失时采用**样本级（sample-level）聚合**——先计算每个序列内的平均损失，再对不同样本取平均。在长CoT场景中，一个回答可能包含数千个token，其中**绝大多数token与最终奖励的相关性极低**。这种“一刀切”的聚合方式**稀释了关键token的梯度信号**。

**解决方案**：DAPO采用**Token级别的策略梯度损失**（Token-Level Policy Gradient Loss）。

在损失聚合模式上，GRPO的“**seq-mean-token-mean**”是**先对每个序列内的token损失取平均，再对序列取平均**；DAPO的“**token-mean**”则是直接**对所有序列的所有token的损失取平均**

**原理深度解析**：

这两种聚合方式看似只是计算顺序的差异，但在长序列场景中影响巨大。

在“**seq-mean-token-mean**”模式下，一个长度为10000的序列和一个长度为100的序列在最终损失中拥有**相同的权重**（都是先序列内平均，再序列间平均）。这意味着**短序列中的每个token获得了远高于长序列中每个token的梯度影响力**。

而在“**token-mean**”模式下，**所有token平等对待**——长序列中成千上万个token的梯度信号不会被压缩到一个“**序列平均值**”中再与其他序列平均。这确保了长CoT中**每一个token的贡献**都被充分考虑到；**梯度信号**更加精细和丰富；模型可以更精准地学习**哪些token模式导致了高奖励**。

实验数据验证了这一点：**移除Token-Level Loss后，DAPO的性能从52%下降到44%**——8个百分点的巨大差距，充分说明了在长CoT场景中token级别的梯度精细化的重要性。

### 3.4 Overlong Reward Shaping：驯服“越长越好”的奖励黑客

**解决的问题**：在长CoT RL训练中，模型很容易发现一个“投机取巧”的策略——**生成更长的回答往往能获得更高的奖励**，因为更长的推理链有更大的概率“蒙”到正确答案。这导致模型**倾向于生成越来越长的输出**，最终超出上下文长度限制，造成训练崩溃。

**解决方案**：DAPO引入**过长奖励塑形（Overlong Reward Shaping）** 。

具体机制是：设定一个`max_response_length`（硬截断上限）和一个`overlong_buffer_len`（缓冲区间）。当回答长度超过`max_response_length - overlong_buffer_len`时，**奖励开始线性下降**：

$$\text{overlong\_reward} = -\min\left(\frac{\text{exceed\_len}}{\text{overlong\_buffer\_len}} \times \text{penalty\_factor},\ 0\right)$$

**原理深度解析**：

这个设计非常巧妙，它不是“**硬截断**”（超过长度直接丢弃或给0分），而是**渐进式惩罚**：

- 在缓冲区内，奖励随长度增加**线性递减**，形成一个“**软边界**”
- 这给模型一个**平滑的梯度信号**：它知道“再长一点就会受到惩罚”，从而学会在**质量和长度**之间寻找平衡
- 惩罚因子`penalty_factor`控制惩罚的**强度**，默认为1.0

相比之下，硬截断会导致**奖励的剧烈不连续性**——一个长度为16383的回答可能获得满分，而长度为16384的回答直接得0分。这种不连续性会让RL训练变得极其不稳定。

值得注意的是，在DAPO论文的最佳性能实验中，**Overlong Filtering（硬过滤）并未被启用**，因为其功能与Overlong Reward Shaping有所重叠。这说明**渐进式惩罚已经足够有效地控制了长度爆炸问题**，无需额外的硬过滤机制。

## 四、DAPO的完整目标函数

综合上述四项技术，DAPO的完整目标函数可以表示为：

$$
\mathcal{J}_{\text{DAPO}}(\theta) = \mathbb{E}_{(q,a)\sim\mathcal{D},\{o_i\}_{i=1}^G\sim\pi_{\theta_{\text{old}}}(\cdot|q)} \left[ \frac{1}{\sum_{i=1}^G |o_i|} \sum_{i=1}^G \sum_{t=1}^{|o_i|} \min\left(r_{i,t}(\theta)\hat{A}_{i,t},\ \text{clip}(r_{i,t}(\theta), 1-\epsilon_{\text{low}}, 1+\epsilon_{\text{high}})\hat{A}_{i,t}\right) \right]
$$

这个公式中的每个部分都有明确的定义：

- **\(r_{i,t}(\theta)\)**：**重要性采样比率**。它衡量的是在当前新策略 \(\pi_{\theta}\) 下，生成第 \(i\) 个回答中第 \(t\) 个token的概率，相较于旧策略 \(\pi_{\theta_{\text{old}}}\) 的变化比例。
- **\(\hat{A}_{i,t}\)**：**组相对优势**。这个值是通过**将同一组内所有回答的奖励进行归一化**得到的，用来衡量某个回答相对于同组其他回答的好坏程度。
- **\(\epsilon_{\text{low}}\)** 和 **\(\epsilon_{\text{high}}\)**：**解耦的裁剪范围**。这是DAPO的“Clip-Higher”技术的核心，它允许对策略更新的上下界（\(\epsilon_{\text{low}}\) 和 \(\epsilon_{\text{high}}\)）进行独立设置，典型值为 \(0.2\) 和 \(0.28\)。
- **\(\frac{1}{\sum_{i=1}^G |o_i|}\)**：这个归一化因子体现了 **Token-Level Policy Gradient Loss**。它意味着损失是**在所有token上取平均**，而不是像GRPO那样先在序列内平均，再在序列间平均。

**关键差异总结**：

| 维度 | GRPO | DAPO |
|------|------|------|
| **裁剪区间** | 对称 $[1-\epsilon, 1+\epsilon]$ | 非对称 $[1-\epsilon_{\text{low}}, 1+\epsilon_{\text{high}}]$（上界更大） |
| **动态采样** | 无 | **过滤全对/全错组** |
| **损失聚合** | 序列级平均 | **Token级平均** |
| **长度控制** | 硬截断 | **渐进式奖励惩罚** |
| **KL散度** | 包含 | **移除** |

## 五、DAPO解决了什么问题？

### 5.1 解决了GRPO在长CoT场景下的熵崩塌问题

通过Clip-Higher的非对称裁剪设计，**DAPO让低概率的“探索”token也能获得有效的概率提升，从根本上打破了熵迅速崩塌的恶性循环**。

### 5.2 解决了无效样本的计算浪费问题

通过**动态采样**，DAPO确保每个训练batch中的每一组数据都能提供**有效的梯度信号**，**大幅提升了样本效率**。

### 5.3 解决了长序列中的梯度稀释问题

通过**Token-Level损失聚合**，DAPO让长CoT中**每一个token**的贡献都能被充分体现，**实现了更精细的策略优化**。

### 5.4 解决了“越长越好”的奖励黑客问题

通过**Overlong Reward Shaping的渐进式惩罚**，DAPO在**鼓励模型探索长推理链**的同时，**有效抑制了长度失控**。

### 5.5 解决了RL训练的可复现性问题

DAPO团队**完整开源了其训练代码、数据集和详细配置**，使得整个社区都能够复现其工业级的RL训练结果——这在之前是几乎不可能的。

## 七、DAPO的适应场景

DAPO在以下场景中表现尤为出色：

1. **长思维链推理训练**：这是DAPO被设计出来的核心场景，在**数学推理（AIME）、代码生成**等需要长CoT的任务上效果显著。

2. **可验证奖励的任务**：DAPO采用**基于规则的奖励模型**（最终答案是否正确），**无需训练独立的奖励模型**，避免了奖励黑客问题。

3. **需要大规模并行训练的场景**：DAPO基于verl框架实现，天然支持**分布式**训练。

4. **追求SOTA推理能力的团队**：DAPO在AIME 2024上达到了50分的SOTA水平。

5. **需要可复现RL训练的团队**：DAPO完整开源了代码、数据和配置，使得复现工业级RL结果成为可能。

## 八、DAPO的优缺点

### 8.1 优点

| 优点 | 说明 |
|------|------|
| **解决熵崩塌** | Clip-Higher从根本上打破了**探索不足的恶性循环** |
| **样本效率高** | **动态采样**确保每个batch的数据都有价值 |
| **梯度精细** | **Token-Level损失**让长序列中每个token都有贡献 |
| **长度可控** | **渐进式惩罚**有效抑制长度爆炸 |
| **可复现性强** | 完整开源，社区可复现工业级结果 |
| **性能SOTA** | AIME 2024上50分，超越DeepSeek-R1-Zero |
| **训练高效** | 50%步数达到SOTA |
| **无需KL散度** | 移除了不必要的KL约束，释放模型探索能力 |

### 8.2 缺点

| 缺点 | 说明 |
|------|------|
| **超参数增多** | Clip-Higher引入了$\epsilon_{\text{low}}$和$\epsilon_{\text{high}}$两个独立超参数 |
| **动态采样有额外开销** | 需要**反复采样**直到累积足够的有效组，可能增加生成开销 |
| **依赖可验证奖励** | 目前主要适用于**有明确答案的任务**（数学、代码），泛化到开放式任务需额外设计 |
| **仍存在训练不稳定性风险** | 尽管有所改善，大规模RL训练仍然存在崩溃风险 |
| **主要在32B规模验证** | 在更大规模模型上的效果有待进一步验证 |
| **Overlong Shaping参数敏感** | 缓冲区间长度和惩罚因子需要根据任务调优 |

---

## 九、总结

如果说GRPO回答的是“**如何用组内相对比较替代价值网络**”的问题，那么DAPO回答的则是一个更为工程化但也更为现实的问题：**如何将GRPO从一个“理论上优雅”的算法，打磨成一个“工业上可用”的系统？**

DAPO通过四项精妙的技术创新给出了答案：

1. **Clip-Higher**：通过**非对称裁剪**，给了低概率token一个“翻身”的机会，从根本上打破了熵崩塌
2. **Dynamic Sampling**：通过**过滤无效组**，确保每一份计算资源都花在刀刃上
3. **Token-Level Loss**：通过**精细化的梯度聚合**，让长序列中每一个token都能为策略优化做出贡献
4. **Overlong Reward Shaping**：通过**渐进式惩罚**，在**鼓励探索和控制长度**之间找到了优雅的平衡

这四项技术没有一项是“颠覆性”的创新——每一项都是**对现有机制的精心调优和改良**。但正是这些“小而精”的改进汇聚在一起，将GRPO从30分推到了50分，超越了DeepSeek-R1-Zero的成绩，且仅用了50%的训练步数。

DAPO给我们的最大启示或许在于：在大模型强化学习对齐这个领域，**“算法框架”只是起点，“训练细节”才是决定成败的关键**。从PPO到GRPO是框架层面的飞跃，而从GRPO到DAPO则是工程层面的精雕细琢。两者缺一不可。DAPO的完整开源，使得整个社区都能够站在巨人的肩膀上继续前进——这或许比算法本身的改进更具长远意义。
